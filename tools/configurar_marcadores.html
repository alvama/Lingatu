Configurar importación de marcadores

Genera el archivo marcadores_config.json que usa convertir_marcadores.py para pasar tus marcadores de Chrome y/o Edge a Lingatu. Esta página no lee ni escribe nada por sí sola — solo prepara el archivo de configuración para que lo descargues y lo guardes junto al script.

Fuentes (una por cada navegador/perfil)

Archivo de salida

¿Dónde está mi archivo "Bookmarks"?
Windows · Edge%LOCALAPPDATA%\Microsoft\Edge\User Data\<Perfil>\Bookmarks
Windows · Chrome%LOCALAPPDATA%\Google\Chrome\User Data\<Perfil>\Bookmarks
macOS · Edge~/Library/Application Support/Microsoft Edge/<Perfil>/Bookmarks
macOS · Chrome~/Library/Application Support/Google/Chrome/<Perfil>/Bookmarks
Linux · Edge~/.config/microsoft-edge/<Perfil>/Bookmarks
Linux · Chrome~/.config/google-chrome/<Perfil>/Bookmarks

<Perfil> suele ser Default para el primer perfil, y Profile 1, Profile 2... para los siguientes. Para saber cuál es el tuyo, abre chrome://version o edge://version en el navegador correspondiente y mira el campo "Ruta del perfil".
